最後更新日期：2026年10月2日

感謝您使用「賓果小瑪莉麻仔台 - 經典水果老虎機」（以下簡稱「本應用程式」）。

本隱私權政策說明本應用程式在您使用過程中涉及的資料收集、使用及第三方服務處理方式。 請您在使用本應用程式前閱讀本政策。

一、我們可能處理的資訊

為提供、維護、分析及改善本應用程式，本應用程式及其所使用的第三方服務可能處理以下資訊。

1. 應用程式產生的隨機識別碼

本應用程式可能在啟動或首次使用時產生一組隨機識別碼，用於識別本應用程式的安裝或使用狀態。

該識別碼由本應用程式自行產生，並非 Android 裝置的硬體唯一識別碼。 本應用程式不會透過該識別碼讀取或取得：

  • IMEI
  • 裝置序號
  • SIM 卡識別資訊
  • 其他硬體唯一識別碼

該識別碼本身不包含您的姓名、電話號碼或電子郵件地址。

2. IP 位址

當您使用需要網路連線的功能時，網路通信可能包含您的 IP 位址。

IP 位址可能由本應用程式所使用的網路服務及第三方服務處理， 其用途可能包括：

  • 提供網路服務
  • 維持服務正常運作
  • 安全性及防止濫用
  • 異常流量及無效流量檢測
  • 統計及分析
  • 廣告服務

3. 時區資訊

本應用程式可能讀取裝置所提供的時區資訊，例如 UTC+8。

時區資訊可能用於時間相關功能及統計分析。

本應用程式不會使用 GPS、Wi-Fi 定位或 Android 位置權限取得您的精確地理位置。 本應用程式不要求使用者授予精確位置或粗略位置權限。

二、Google Firebase Analytics

本應用程式使用 Google Firebase Analytics，以了解使用者如何使用本應用程式， 協助我們分析及改善應用程式功能及使用體驗。

Firebase Analytics 可能處理與應用程式使用相關的資訊，例如：

  • 應用程式使用事件
  • 應用程式版本
  • 作業系統及應用程式相關資訊
  • Firebase Installation ID 等安裝識別資訊
  • 其他用於分析應用程式使用情況的技術資訊

Firebase Analytics 所處理的資料主要用於統計分析、了解功能使用情況及改善本應用程式。

三、Google Firebase Remote Config

本應用程式使用 Google Firebase Remote Config，用於遠端管理及調整部分應用程式設定。

Remote Config 可讓我們在不發布新版應用程式的情況下調整部分設定及功能參數。

其用途可能包括：

  • 應用程式設定管理
  • 功能參數調整
  • 遊戲內容及功能配置
  • 改善應用程式使用體驗

Remote Config 可能處理與應用程式安裝及使用環境相關的技術資訊， 以判斷及提供適用的遠端設定。

四、Google AdMob

本應用程式使用 Google AdMob 提供廣告服務。

AdMob 可能處理與廣告請求、廣告展示及廣告互動相關的資訊， 包括但不限於：

  • IP 位址
  • 應用程式及裝置相關資訊
  • 廣告相關識別資訊
  • 廣告請求及展示資訊
  • 診斷及效能相關資訊
  • 其他提供廣告服務所需的技術資訊

上述資料可能用於：

  • 提供廣告
  • 衡量廣告效果
  • 防止無效流量及濫用
  • 改善廣告服務

五、歐洲經濟區、英國及瑞士使用者

對於位於歐洲經濟區（EEA）、英國及瑞士的使用者， 本應用程式使用 Google User Messaging Platform（UMP）處理適用的廣告同意流程。

在適用法律及 Google 政策要求取得使用者同意的情況下， 本應用程式會在提供個人化廣告前取得必要的同意。

使用者可以依照應用程式提供的隱私或同意管理介面， 在適用情況下查看、修改或撤回相關選擇。

如果使用者拒絕個人化廣告相關同意，廣告服務可能依照 Google 及適用法律的規則提供非個人化或其他符合規定的廣告。

六、資料使用目的

我們及本應用程式所使用的第三方服務可能基於以下目的處理相關資料：

  • 進行應用程式使用統計及分析
